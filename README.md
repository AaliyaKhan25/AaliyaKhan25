## 🚀 Featured Projects

**🎙️ [Hacker House Goa](https://ragingoa.netlify.app/) — Voice-Enabled RAG Pipeline**
A full voice-to-answer pipeline: records or uploads audio, transcribes it offline via **Sarvam STT (saarika:v2.5)**, retrieves relevant context using **MiniLM embeddings + FAISS**, and generates answers with **Groq's gpt-oss-20b**.
`Python` `Sarvam API` `FAISS` `MiniLM` `Groq API` `RAG`

**🛡️ [PRAHAAR-AI](https://github.com/devansh6291/prahaar-ai-defense-2.0)** — Command & Control System · *1st Place, AAROHAN Techfest*
